# Pi

Кандидат для роли Orchestrator и других специализаций, **если проверена** пригодность его инструментов и расширений в среде пользователя.

Уточни реальную команду (возможный кандидат `pi`), версию, провайдеров, модели, точные параметры, доступные инструменты, расширения, ограничения и способность вызывать внешние CLI. Подключение провайдера в Pi не означает разрешения использовать его с кодом данного проекта.

Процесс выбора: `docs/HARNESS_ROUTING.md`. AEK не создаёт автоматическую связь между харнессами одной текстовой инструкцией.

Для нативных `/aek_greenfield`, `/aek_brownfield`, `/aek_update` используй шаблоны `.pi/prompts/<name>.md` либо глобальные `~/.pi/agent/prompts/<name>.md`. Установка через `tools/aek_shortcuts.py` показывает план и не перезаписывает чужие команды. В Pi проверь реальную загрузку и настройку доверия проекту.
