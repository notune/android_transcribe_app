# DSH (DeepSeek Harness)

Кандидат на роль с поддержкой режима DSH, указанного пользователем. Фактические команды, авторизация, модели Flash/Pro, опции и возможности делегирования зависят от установленной версии.

Проверяй путь команды и версию; не открывай и не выводи секреты. Уточняй разрешение на передачу исходников соответствующему провайдеру и проверяй ограничения API/аккаунта. Не считай наличие файла адаптера доказательством автоматического запуска DSH из AEK.

Процесс выбора: `docs/HARNESS_ROUTING.md`.
