# Codex

Используй `AGENTS.md` и проектные навыки `.agents/skills/aek-*/SKILL.md`. Названия переносимых навыков соответствуют Agent Skills: строчные буквы, цифры и дефисы.

Быстрые вызовы: `$aek-greenfield`, `$aek-brownfield`, `$aek-update`, `$aek-change` и остальные. Имя с подчёркиванием `$aek_update` не генерируется. В T3 Code навыки могут отображаться и в меню `/`; проверь настройку отображения и перезапусти агентную сессию после регистрации.

[Регистрация и таблица соответствия](../../docs/SHORTCUTS.md). Наличие навыка в каталоге не доказывает его исполнение. Проверяй фактическую модель, права, инструменты и результаты задачи.
