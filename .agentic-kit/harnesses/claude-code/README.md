# Claude Code

Общие правила: `AGENTS.md`, применимая роль и требования проекта. Если среда читает `CLAUDE.md`, добавь ссылку на AEK после проверки существующих инструкций.

Нативные команды `/aek_greenfield`, `/aek_update` и остальные находятся в `.claude/commands/aek_<action>.md` либо `~/.claude/commands/`. Их регистрирует `tools/aek_shortcuts.py` через план. Переносимые канонические навыки в исходном комплекте имеют имена с дефисом.

После изменения команд перезапусти агентную сессию T3 Code и проверь реальный вызов. [Команды и ограничения](../../docs/SHORTCUTS.md). Модели и права автоматически не назначаются.
