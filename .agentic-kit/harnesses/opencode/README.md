# opencode

Проверь реальную конфигурацию провайдеров, модели, подпроцессы и разрешения на инструменты. Не расширяй права для ускорения работы.

Единые правила живут в AGENTS.md, docs/ и roles/. Адаптер должен только отражать специфический механизм загрузки и не дублировать методологию.

Для нативных `/aek_greenfield`, `/aek_brownfield`, `/aek_update` используются `.opencode/commands/<name>.md` или глобальные `~/.config/opencode/commands/<name>.md`. Их создаёт `tools/aek_shortcuts.py` только после предварительного просмотра и разрешения. Команды являются текстовыми шаблонами с `$ARGUMENTS`, без автоматического выполнения shell.
