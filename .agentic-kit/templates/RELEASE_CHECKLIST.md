## Версия и совместимость

- [ ] Подтверждено, что требуется выпуск, а не просто завершение этапа.
- [ ] Выбрана версия с учётом изменения публичного контракта.
- [ ] Согласованы метаданные пакета, CLI, API и файл блокировки зависимостей по применимости.
- [ ] В `CHANGELOG.md` новые изменения отделены от старых выпусков.
- [ ] Подготовлены миграция и откат, если изменены данные или контракт.

## Проверки и артефакты

- [ ] Зафиксирован точный полный SHA исходного коммита.
- [ ] Тесты, безопасность и независимая приёмка проверены по риску.
- [ ] Выполнены требуемые сборка, установка и проверка запуска.
- [ ] Сохранены фактические контрольные суммы артефактов, если они поставляются.
- [ ] После проверки не внесено непроверенных изменений кода.
- [ ] Составлены сведения о выпуске и ограничения.

## Разрешения и публикация

- [ ] Проверено отсутствие конфликта Git-тега локально и на сервере.
- [ ] Тег соответствует версии и указывает на принятый коммит; старые теги не перемещаются.
- [ ] Получено отдельное разрешение на создание и отправку тега.
- [ ] Получено разрешение на GitHub Release, публикацию пакетов и развёртывание, когда применимо.
- [ ] После публикации сверен тег, SHA, номер версии и опубликованные артефакты.
