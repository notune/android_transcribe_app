# Visual QA: отчёт по настоящему браузеру

Применяется к любому затронутому UI, в том числе `lite`. Не заполнять по догадкам модели.

- Создай отчёт JSON в `.agentic-kit/evidence/<task>/visual-qa.json` и снимки в том же закрытом каталоге.
- Проверь URL работающего приложения, браузер и точную версию, размер окна, сценарий, ожидаемый и фактический результат.
- Пройди сценарии клавиатурой, проверь начальный и возвращаемый фокус, сообщения об ошибках, консоль браузера и сетевые запросы.
- Отдельно укажи ошибки сети и консоли даже при визуально корректной странице. Результат `passed` допустим только без нерешённых ошибок.
- Привяжи отчёт к полному `git rev-parse HEAD`; снимки и отчёт должны соответствовать проверяемому состоянию кода.
- Запуск браузерных тестов фиксируй через `record --key tests --run`; сам отчёт Visual QA с файлами снимков экрана записывается через `record --key visual_qa --file`.
- Не сохраняй личные данные и секреты на снимках, в сетевых трассировках и в Git. При отсутствии браузера укажи блокировку и запроси отдельное согласование исключения.

Пример структуры (замени все значения реальными):

```json
{
  "browser": "Chromium",
  "browser_version": "ПО ФАКТУ",
  "url": "http://127.0.0.1:8000",
  "viewport": {"width": 1440, "height": 900},
  "scenarios": [
    {
      "name": "Создать проект",
      "expected": "После подтверждения проект появляется в списке",
      "actual": "ПО ФАКТУ",
      "passed": true
    }
  ],
  "screenshots": [".agentic-kit/evidence/TASK-001/projects.png"],
  "console_errors": [],
  "network_errors": [],
  "keyboard": "Фактическая проверка Tab, Enter, Escape",
  "focus": "Фактическое поведение фокуса и его возврата",
  "result": "passed",
  "git_commit": "ПОЛНЫЙ_SHA_ПРОВЕРЕННОГО_КОММИТА"
}
```

Поля `screenshots` указывают на реальные файлы внутри проекта. Для отчёта `visual_qa` AEK сохраняет их SHA256 и проверяет целостность. Но содержимое отчёта остаётся заявлением исполнителя. Для независимого контроля повтори браузерные тесты в защищённом CI.

Команда регистрации:

```bash
python3 .agentic-kit/tools/aek.py record --target . --task TASK-001 --key visual_qa --file .agentic-kit/evidence/TASK-001/visual-qa.json
```
