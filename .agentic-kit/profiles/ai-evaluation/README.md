# AI Evaluation — подключаемый профиль AEK

**Триггер:** продукт содержит LLM, RAG, агентную систему, оцениваемые ответы/инструментальные действия; требуется проверка качества, регрессий или безопасности модельного поведения. Не подключать для обычных приложений без ИИ.

**Роли:** AI/ML Engineer (функция), QA (эвалы), Security (red teaming), PM/BA (критерии успеха).

**Первоисточник:** https://github.com/promptfoo/promptfoo, просмотренный commit `841036f4fde86b4258b9357cba4288c963b3a647`. Официальный `.claude/skills/promptfoo-evals/SKILL.md` описывает функциональные оценки и намеренно исключает настройку атакующего red teaming. Поэтому в AEK функциональные эвалы и безопасность — **разные сценарии**, с разными полномочиями и согласованиями.

## Активация

```bash
python3 tools/aek_activate.py plan --target /path/to/project --profile ai-evaluation
# после согласования:
python3 tools/aek_activate.py apply --target /path/to/project --profile ai-evaluation --plan-id PLAN_ID
```

Профиль добавляет правила, **не** устанавливает Promptfoo, не запускает запросы к моделям и не отправляет тестовые данные внешним провайдерам. При проектировании оценок сначала фиксируй целевое поведение, контрольный набор, метрики, пороги и политику данных. Отдельное разрешение нужно на red team, внешние вызовы и расходы токенов.
