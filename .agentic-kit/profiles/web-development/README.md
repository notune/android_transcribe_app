# Web Development — профиль AEK

**Не является обязательной частью ядра.** Включать только если продукт содержит браузерный интерфейс или значимый клиентский HTML/CSS/JavaScript. Применяется к React/Vue/Svelte и другим веб-продуктам, но не к чистому backend, CI/CD, нативным мобильным приложениям и нерелевантным задачам.

## Цель

Применять актуальные браузерные возможности, доступность, производительность и безопасные API без неоправданных зависимостей и собственного кода. Сначала проверить существующие компоненты, потом возможности платформы и зрелые библиотеки, затем обосновывать собственное решение.

**Совместимость с текущими практиками:**
- Product Designer: UI/UX Pro Max, Frontend Design — макеты и визуальная система; Modern Web Guidance — корректность нативных паттернов UI.
- Architect: проверяет браузерную поддержку, альтернативы библиотекам, сложность fallback.
- Frontend Engineer: использует Modern Web Guidance при создании/изменении существенных HTML/CSS/client JS компонентов.
- QA: оценивает функциональность и доступность, совместимость браузеров и web vitals, не подменяя тесты чтением гайдов.
- Security: использует рекомендации о нативной веб-безопасности только как дополнительный источник, не вместо OWASP ASVS и Threat Modeling.

## Рекомендуемая основа для новых React-проектов

Для новых веб-приложений на **React** предлагаем согласовать [shadcn/ui](https://ui.shadcn.com), [Base UI](https://base-ui.com) и [Tailwind CSS](https://tailwindcss.com). Это рекомендуемый набор для оформления и поведения компонентов, а не обязательная установка во все проекты. С июля 2026 года shadcn/ui рекомендует Base UI для новых проектов и продолжает поддерживать Radix для существующих. При обзоре официальный исходный коммит shadcn/ui: `e62c9435fff729a175f38983dee73b2cb4f6a069`.

Сначала утверди сценарии, визуальную систему, тему, шрифты, цвета, таблицы/формы, состояния, адаптивность и прототип. После одобрения сравни текущий стек, версию React, библиотеки, доступность и стоимость сопровождения; затем получи отдельное разрешение на установку нужных компонентов. В shadcn/ui код копируется в репозиторий продукта и сопровождается самим проектом. Скопированные компоненты нельзя автоматически перезаписывать при обновлениях.

Для внутренней административной панели Mantine допустим как альтернатива. Для действующих React-продуктов **не** переводить существующий Radix, MUI, Mantine или другую библиотеку на Base UI без специального решения. Для Vue/Svelte/Solid не применять React-ориентированный выбор автоматически.

## Поведение и доступность веб-интерфейса

Для существенных интерактивных элементов применяй [критерии AEK](../../docs/DESIGN.md): действия с клавиатуры, фокус и его возврат, доступные названия, состояния ошибок и отмену. Проверяй результат в реальном браузере. Это дополнение к Visual QA и принятой библиотеке компонентов, а не причина заменять существующий интерфейс.

При необходимости взаимодействия ИИ-агента с продуктом сначала согласуй доступные действия, видимость данных, подтверждения и серверные проверки полномочий.

**Необязательный источник:** [Vercel UI SDK](https://github.com/vercel-labs/ui), обзор коммита `c53df2f45c7502bebf0f52619dfe75007a309eb6`, лицензия Apache-2.0, версия beta. Используй только после сравнения с действующей библиотекой и отдельного согласования. Пакеты `@ui-sdk/*` и сторонний скилл `ui-sdk` не устанавливаются автоматически при активации профиля AEK.

## Установка профиля (только после установки AEK)

Из исходного клона AEK:

```bash
python3 tools/aek_activate.py plan --target /path/to/project --profile web-development
# После просмотра плана и согласования:
python3 tools/aek_activate.py apply --target /path/to/project --profile web-development --plan-id PLAN_ID
python3 tools/aek_activate.py check --target /path/to/project --profile web-development
```

Профиль регистрирует локальный скилл `aek-modern-web-guidance` в `.agents/skills/`. Он не скачивает CLI и не выполняет сетевые запросы при активации.

## Внешний источник и безопасность

- Официальный репозиторий: https://github.com/GoogleChrome/modern-web-guidance
- Версия CLI, выбранная для пилота: `modern-web-guidance@1.0.0` (точная, **не** `@latest`).
- Рекомендуемая версия набора рекомендаций: `2026_11_09-5bcc021b`. Обновлять после проверки документации/совместимости.
- Лицензия исходного проекта: Apache-2.0. Содержимое стороннего скилла в AEK не копируется.
- Загрузка через npx требует разрешённого сетевого доступа. Не выполняй её без согласования; перед запуском проверь npm-пакет и источник.
- Установи `DISABLE_TELEMETRY=1` при поиске/получении рекомендаций; не передавай внутренние данные проекта в поисковые запросы.
- `legacy-scan` используется только для запрошенного общего анализа устаревших веб-паттернов и проверяется вручную на ложные срабатывания.

**Chrome Extensions:** у GoogleChrome есть отдельный `chrome-extensions` skill, но он не включён в этот профиль и подключается только при реальной разработке расширений браузера.

Референс внешней зависимости: [manifest.json](manifest.json). Правила вызова: [aek-modern-web-guidance](skills/modern-web-guidance/SKILL.md).
