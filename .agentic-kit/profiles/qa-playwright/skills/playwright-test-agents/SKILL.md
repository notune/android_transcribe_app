# Playwright Test Agents — профиль QA

1. Проверь наличие браузера **у выбранного агента**, существующих E2E-тестов, фикстур и тестовой среды. Для взаимодействия агента с интерфейсом предпочитай Playwright MCP; Chrome DevTools MCP подключай отдельно для диагностики; Playwright CLI используй, если MCP не поддерживается; Playwright Test в CI. Не вводи новый стек без Architecture Simplification Gate.
2. Используй согласованный OpenSpec, UX-потоки и критерии приёмки для тестового плана. Для UI до проектирования проверь `browser_capability` и статус в `.agentic-kit/templates/HARNESS_DISCOVERY.md`. Не создавай тесты на основе догадок агента.
3. Если соответствующая версия Playwright и харнесс поддерживают Test Agents, **после согласования** можно сгенерировать определения штатной командой Playwright `init-agents`. Проверь diff; не перезаписывай пользовательские инструкции и конфигурации.
4. Planner → test plan; Generator → E2E-тесты; Healer → повторный запуск и исправление **тестового кода**, если ошибка в тесте, а не в продукте. Нельзя ослаблять assertions ради зелёного статуса.
5. Для затронутых интерактивных компонентов проверь клавиатуру (Tab, стрелки, Enter, Space, Escape, где применимо), фокус и его возврат, роли и названия ARIA, ошибки, открытие, закрытие и отмену. Зависимое от браузера поведение проверь в настоящем браузере; см. `.agentic-kit/docs/DESIGN.md`.
6. Для новых важных тестов, если разрешено и безопасно, в изолированной среде временно нарушь проверяемое поведение, убедись, что тест обнаруживает ошибку, затем восстанови код. В продуктивной среде так не действуй.
7. Для интерфейса ИИ-агента отдельно проверь запреты действий, подтверждения, скрытие чувствительных данных и серверную проверку полномочий. Не считай проверку браузерного кода границей безопасности.
8. Сделай реальные снимки и отчёт по `.agentic-kit/templates/VISUAL_QA.md`, зарегистрируй подтверждающие файлы и код запуска в задаче AEK, при возможности выполни CI-тесты. Укажи, какие сценарии реально запускались, какие не проверены, и где причина: дефект приложения, теста или среды. Не ослабляй утверждённые критерии ради успешных проверок.

**Источник:** https://github.com/microsoft/playwright/blob/main/docs/src/test-agents-js.md. Этот AEK skill не содержит Playwright и не выполняет установку браузеров/агентов при активации.
