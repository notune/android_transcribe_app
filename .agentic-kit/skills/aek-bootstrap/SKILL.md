# Подключение AEK

Используй при явном запросе подключить или обновить AEK. Источник: https://github.com/kelvmg/agentic-engineering-kit, отдельный проверенный клон вне целевого проекта. Не передавай токены в чат.

1. Проверь корень проекта, инструкции, состояние Git и наличие `.agentic-kit/install-manifest.json`.
2. Для нового подключения прочитай `docs/BOOTSTRAP.md`, `docs/NEW_PROJECT.md` и `docs/ADOPTION.md`. Новый пустой каталог: `new-project` (каркас, кит, навыки, команды, проверки, коммит, `handoff` для регистрации и потока); действующий код: `install --mode existing`.
3. Для существующего каталога выполни `aek.py install --target PATH --mode MODE --activate`. Покажи единый план с `plan_id`, включая корневые инструкции и навыки. При применении используй тот же набор параметров и `--apply --plan-id ID`.
4. Повторное согласование уже одобренного неизменившегося плана не требуется. Новый объём работ, конфликт или изменение плана требуют решения пользователя.
5. Для уже установленного кита используй `aek.py update` и `docs/COMPONENTS.md`. Низкоуровневый `upgrade` обновляет только кит и активированные проектные навыки.
6. Проверь результат и доступность команд у выбранного провайдера. Файлы на диске не доказывают загрузку навыка.
7. Продолжай по `docs/DAILY_WORKFLOW.md`. Сторонние инструменты не принимаются под управление без явной регистрации.

Короткие команды: `/aek_greenfield`, `/aek_brownfield`, `/aek_update`. Codex: `$aek-greenfield`, `$aek-brownfield`, `$aek-update`. Точное соответствие и регистрация описаны в `docs/SHORTCUTS.md`.
