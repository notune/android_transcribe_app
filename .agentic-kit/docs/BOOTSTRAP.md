# Подключение AEK из агентного интерфейса

Источник: https://github.com/kelvmg/agentic-engineering-kit. Получи комплект через уже настроенную авторизацию GitHub в отдельный каталог **вне проекта**, проверь исходники и зафиксируй полный commit SHA. Не передавай токены в чат и не запускай `curl | bash`.

## Быстрый вход

В T3 Code или другом интерфейсе используй `/aek_greenfield` для нового проекта либо `/aek_brownfield` для существующего. Для нового проекта заранее открывать каталог не нужно: достаточно пустого каталога и названия — команда создаст каркас, поставит кит и навыки, а затем зарегистрирует проект и откроет в нём поток. Если у сессии нет инструментов регистрации, она выдаёт `handoff` для той, у которой они есть. Полная процедура: [NEW_PROJECT.md](NEW_PROJECT.md). Для Codex переносимые навыки называются `$aek-greenfield` и `$aek-brownfield`: стандарт имён Agent Skills допускает дефис, а не подчёркивание. Точное соответствие провайдеров приведено в [SHORTCUTS.md](SHORTCUTS.md).

Команды можно зарегистрировать один раз глобально по инструкции SHORTCUTS. Если их ещё нет, дай агенту ссылку на этот документ. Установка файлов не доказывает, что выбранный провайдер загрузил навык.

## Единый план подключения

Установка и активация выполняются одним просмотренным планом. Из отдельного клона AEK:

```bash
python3 tools/aek.py inspect --target /absolute/path/to/product
python3 tools/aek.py install --target /absolute/path/to/product --mode existing --activate
# После просмотра плана, в пределах полученного разрешения:
python3 tools/aek.py install --target /absolute/path/to/product --mode existing --activate --apply --plan-id PLAN_ID
python3 tools/aek_activate.py check --target /absolute/path/to/product
```

Для нового проекта замени `existing` на `new`. Целевая папка должна существовать. Новый проект может содержать Git, README, лицензию и начальные инструкции; значимый код требует режима `existing`. Повторная установка при наличии манифеста запрещена, используй обновление.

План содержит создаваемые, изменяемые и конфликтующие файлы, версию и `plan_id`. Он ничего не записывает. Применение заново рассчитывает план и отклоняет устаревший идентификатор. Изменение профилей или файлов после просмотра требует нового плана. Уже полученное разрешение на неизменившийся объём не запрашивается повторно.

`--activate` включает в тот же план регистрацию проектных навыков и дополнение `AGENTS.md`. Исходные правила сохраняются; существующая ссылка на AEK не дублируется. Необязательные профили явно включаются повторяемым параметром, например `--profile qa-playwright`; этот же набор передаётся при применении и проверке.

## Отдельная активация

Если установлен только комплект файлов, навыки можно зарегистрировать позже:

```bash
python3 tools/aek_activate.py plan --target /absolute/path/to/product --profile qa-playwright
python3 tools/aek_activate.py apply --target /absolute/path/to/product --profile qa-playwright --plan-id PLAN_ID
python3 tools/aek_activate.py check --target /absolute/path/to/product --profile qa-playwright
```

Активация сохраняет контрольные суммы зарегистрированных навыков и активные профили в манифесте. Конфликтующая пользовательская копия блокирует применение. Сторонние инструменты и библиотеки здесь не скачиваются.

## Границы и восстановление

Установщик проверяет символические ссылки в управляемых исходниках и целевых путях, сохраняет чужие файлы и блокирует конфликтующие операции. При обычной ошибке записи завершённые изменения восстанавливаются. Блокировка предотвращает одновременную работу сотрудничающих установщиков; она не защищает от произвольного процесса с теми же правами. При аварийном завершении процесса или отключении питания проверь состояние перед повторным запуском.

Код приложения, зависимости, CI, OpenSpec, настройки T3 Code и секреты не меняются. Глобальные команды устанавливаются отдельным явно выбранным действием.

## Проверка в провайдере

После подключения перезапусти агентную сессию в целевом окружении T3 Code и проверь доступность навыков и выполнение безопасного задания. Для каждого провайдера отдельно зафиксируй результат: наличие файлов не подтверждает загрузку инструкций или доступ к модели.

Перед первой существенной задачей проверь разрешённые инструменты, модели и доступы; сохрани задачу через `aek.py new-task`. Для UI отдельно проверь браузер. Если среда его не предоставляет, визуальная проверка остаётся невыполненной до согласованного решения.

Дальнейшая работа: [WORKFLOW.md](WORKFLOW.md), обновление: [UPGRADE.md](UPGRADE.md). Для независимой блокировки слияния требуются защищённый CI и права утверждения вне изменяемого агентом рабочего каталога.
