## Codebase Audit

[shadcn/improve](https://github.com/shadcn/improve) включён как источник [необязательного пакета навыков](../profiles/codebase-audit/README.md). Используем доказательный анализ, подготовку самостоятельных заданий и проверку актуальности. Сам внешний скилл и его команды исполнения не устанавливаются, чтобы не дублировать OpenSpec и AEK Orchestrator.

## Правило принятия решения

Перед новым пакетом навыков ответь:

1. Есть ли в проекте конкретная задача и подтверждённая технология?
2. Не дублирует ли он AEK или уже установленный skill?
3. Есть ли проверяемый источник, поддержка, ограничения передачи данных, лицензия?
4. Есть ли измеримый выигрыш на контрольных задачах?
5. Можно ли подключить как ссылку или пакет навыков без собственной копии и без фоновой установки?

Сравни небольшие контрольные задания с/без скилла: успешность, качество, время, стоимость, регрессии. При отсутствии пользы не активируй.

**Отдельные ссылки на роли:** PM/BA/Architecture остаются на текущей AEK-методологии; универсальный новый «главный агент» по звёздам GitHub не назначается.
