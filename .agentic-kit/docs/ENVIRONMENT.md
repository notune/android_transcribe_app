# Диагностика среды и маршрутизация

**Обязательный рабочий процесс:** [Harness Discovery & Assignment](HARNESS_ROUTING.md) и `skills/harness-discovery-assignment/SKILL.md`. При старте нового или существующего проекта обнаружь харнессы, проведи минимальный диалог, проверь возможности, предложи и согласуй матрицу ролей, модель/effort, инструменты, полномочия и резервный маршрут.

AEK умеет локально находить **кандидатов** Codex, OpenCode, DSH, Qwen Code и Pi; из обнаружения CLI нельзя делать вывод о доступности моделей, а наличие адаптационной инструкции не означает поддержки автоматического исполнения. Не сканируй токены и не меняй пользовательские конфигурации.

Для каждой роли предложи `primary + fallback` с доказательствами и разрешёнными классами данных. Перед переходом к существенной реализации должно существовать согласованное назначение (для standard/critical — `routes_confirmed`). Не переутверждай ту же матрицу для каждой мелкой задачи без основания.

Полная процедура: [HARNESS_ROUTING.md](HARNESS_ROUTING.md).
