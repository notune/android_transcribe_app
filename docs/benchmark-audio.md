# Тестовая запись для проверки скорости

## Что используется

В приложение встроена одна запись русской речи:

| Параметр | Значение |
|---|---|
| Файл в приложении | `app/src/main/assets/bench.wav` |
| Источник | Google FLEURS, конфигурация `ru_ru`, split `dev` |
| Файл источника | `11322082307290188515.wav` |
| Длительность | 10,56 с |
| Формат в приложении | WAV, 16 кГц, моно, 16-битный PCM |
| Лицензия | Creative Commons Attribution 4.0 (CC BY 4.0) |

Расшифровка источника:

> Во многих случаях поступление на какой-либо курс за границей во время
> академического отпуска действительно может повысить ваши шансы на
> поступление в высшие учебные заведения на родине.

## Указание авторства

Запись взята из набора FLEURS:

- Conneau, A. et al. FLEURS: Few-shot Learning Evaluation of Universal
  Representations of Speech. 2022.
- Набор: <https://huggingface.co/datasets/google/fleurs>
- Лицензия: <https://creativecommons.org/licenses/by/4.0/>

Изменение: исходный файл FLEURS хранится как 32-битный float PCM. Для
встроенного чтения WAV он перекодирован в 16-битный PCM без изменения
частоты дискретизации, числа каналов и длительности. Содержание записи
не менялось.

## Как получить заново

```bash
# 1. Скачать набор (нужен только один файл из dev).
curl -L "https://huggingface.co/datasets/google/fleurs/resolve/main/data/ru_ru/audio/dev.tar.gz" \
  | tar -xzf - dev/11322082307290188515.wav

# 2. Перекодировать в формат приложения.
ffmpeg -y -i dev/11322082307290188515.wav \
  -ar 16000 -ac 1 -c:a pcm_s16le app/src/main/assets/bench.wav

# 3. Проверить формат.
ffprobe -v error -show_entries stream=codec_name,sample_rate,channels,bits_per_sample \
  -show_entries format=duration -of default=nw=1 app/src/main/assets/bench.wav
```

## Почему эта запись

- Русский язык: основная модель GigaAM понимает только русский, поэтому
  английская запись не показывала основной сценарий.
- Около 11 секунд: длительность близка к прежней записи, замеры удобно
  сравнивать.
- Одно длинное предложение с запятыми и числами: очистке есть что
  восстанавливать, а по тексту видно, не потерялись ли детали.
- Открытая лицензия: запись можно распространять с указанием авторства,
  личных данных в ней нет.

## Ограничения

- Это публичная синтетическая фраза, а не диктовка пользователя.
- Запись одинаковая на всех устройствах, поэтому сравнение скоростей
  между устройствами и моделями корректно.
- Качество распознавания зависит от активной модели. Модель, не
  понимающая русский, покажет плохой текст: это честный результат теста,
  а не ошибка приложения.
