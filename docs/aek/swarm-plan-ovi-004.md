# Swarm Planning Gate: OVI-004

## Вывод

Работа идёт одним потоком записи.

## Почему не параллелим

- Меняются связанные места: `main_activity.rs`, `MainActivity`,
  разметка карточки и семь файлов строк. Второй писатель даст конфликт.
- Объём небольшой: один JNI-параметр, один вызов существующего
  `PostProcessor`, один маленький класс логики, строки и тесты.
- Замена записи `bench.wav` и документация также в одном дереве.

## DAG

```
бриф и дизайн (согласованы)
        |
        v
Rust: вернуть текст в Java
        |
        v
BenchmarkLogic и JVM-тесты
        |
        v
MainActivity: второй этап, отмена, результат
        |
        v
разметка, строки, запись FLEURS, docs
        |
        v
сборка, тесты, снимок разрешений
        |
        v
один коммит (SHA)
        |
        v
независимая проверка
```

## Роли

| Роль | Кто | Что делает |
|---|---|---|
| Исполнитель | `opencode`, `s2b/cowork-hard` | код, тесты, документы |
| Проверяющий | `codex`, `gpt-6.1-sol` | чтение кода, запуск тестов, вердикт |
| Интеграция | ведущая сессия | коммит, импорт вердикта, закрытие задачи |

## Общие ресурсы

- Одно рабочее дерево Git, один каталог `app/build`.
- Строки в семи файлах правятся одним потоком.
- Сборка и тесты не запускаются одновременно с правкой.
