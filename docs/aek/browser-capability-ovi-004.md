# Browser Capability: OVI-004

## Вывод

Браузер для этой задачи не применим.

Интерфейс приложения собран на Android Views и работает внутри APK.
Веб-страницы, локального сервера предпросмотра и DOM у задачи нет.
Поэтому проверять карточку теста скорости через браузер нельзя.

## Чем заменяется

Визуальная проверка идёт на реальном устройстве SM-F966B:

- `adb shell uiautomator dump` даёт дерево элементов, тексты, состояния
  переключателей и границы нажатия;
- снимок экрана подтверждает внешний вид карточки и окна результата;
- журнал `logcat` подтверждает отсутствие падений.

Это проверка того же пользовательского интерфейса, который видит человек,
а не имитация в браузере.

## Ограничение

Если появится веб-версия или экран на HTML, это решение нужно пересмотреть
и назначить настоящую браузерную проверку.
