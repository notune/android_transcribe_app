# Architecture Simplification Decision: OVI-003

## Что уже есть и переиспользуется

- `PostProcessingLogic.buildChatCompletionsUrl` уже нормализует адрес:
  добавляет `/v1`, сохраняет полный путь. Для списка моделей нужно то же
  правило с заменой хвоста `/chat/completions` на `/models`.
- `OpenAiCompatibleClient` уже умеет `GET`-совместимый `HttpURLConnection`,
  ограничение ответа 1 МиБ, отключённые переадресации, проверку заголовка
  ключа и короткие ошибки. Новый метод добавляется в тот же класс.
- `PostProcessor` уже даёт фоновое выполнение, сторожевой таймер, отмену
  и доставку результата в главный поток. Новый запрос использует ту же
  схему, а не новый исполнитель.
- `org.json` есть и в Android, и в тестовой зависимости. Новый разбор
  пишется на нём.

## Что можем не делать

- Новую библиотеку HTTP или JSON. Ничего не добавляем.
- Отдельный слой репозитория, кэш на диск, `WorkManager`, повторные
  попытки. Список нужен один раз по нажатию.
- Собственный экран выбора. Хватает окна с полем фильтра и списком.
- Автоматический запрос при открытии экрана. Он тратит ключ и сеть без
  действия пользователя.
- Хранение списка в настройках. Список меняется на сервере, кэш устареет.

## Минимально достаточное решение

Один метод сборки адреса, один метод разбора, один метод `GET`, одна
фоновая обёртка и одно окно. Всего четыре небольших изменения в
существующих классах плюс разметка и строки.

## Влияние на UX, DX, AX

- UX: имя модели больше не угадывается, но ручной ввод остаётся.
- DX: разбор и адрес тестируются на JVM, сеть проверяется отдельно.
- AX: у новой функции свои критерии приёмки и отдельная проверка.

## Отвергнутые варианты

| Вариант | Почему нет |
|---|---|
| Выпадающий список без запроса, из зашитых имён | быстро устаревает, не работает для своих серверов |
| Автодополнение по истории ввода | не решает первый запуск и новые серверы |
| Запрос списка через `/models` без `/v1` | у части серверов путь другой, нормализация надёжнее |
| Кэш списка в `SharedPreferences` | устаревает, даёт ложные имена моделей |
