# Дизайн OVI-004: тест скорости с очисткой

## Граница дизайна

Меняется только карточка «Тест скорости» внизу главного экрана и
встроенная тестовая запись. Новых экранов, навигации и тем нет.
Визуальный язык прежний: Material 3, существующие карточка, текст и
кнопки.

## Элементы карточки

1. Заголовок «Тест скорости» с прежней иконкой микрофона.
2. Описание: русская тестовая запись, длительность, и прямая фраза о
   том, что при включённой очистке распознанный текст уйдёт на
   настроенный сервер, а аудио останется на телефоне.
3. Мелкая строка источника: «Запись: Google FLEURS, CC BY 4.0».
   Отдельный `TextView` с `textAppearanceBodySmall` и
   `colorOnSurfaceVariant`, без ссылки внутри приложения. Полное
   указание авторства в `docs/benchmark-audio.md`.
4. Текст результата, многострочный, `textAppearanceBodyLarge`.
5. Текстовая кнопка «Подробнее», видимая только после успешного
   распознавания. Открывает окно с распознанным и, если он есть,
   очищенным текстом. Тексты можно выделить и скопировать.
6. Кнопка «Запустить тест» прежняя, на всю ширину.

## Состояния

| Состояние | Карточка | Сеть |
|---|---|---|
| Идёт распознавание | «Идёт тест…», кнопка недоступна | нет |
| Идёт очистка | «Идёт тест…», кнопка недоступна | запрос очистки |
| Успех, очистка включена и настроена | Время распознавания, коэффициент, время очистки, общее время; кнопка «Подробнее» | да |
| Успех, очистка выключена | Время распознавания и коэффициент, строка «Очистка выключена, текст не отправлялся»; «Подробнее» с одним текстом | нет |
| Успех, очистка включена без адреса или модели | Время распознавания и строка «Очистка не настроена»; «Подробнее» с одним текстом | нет |
| Ошибка очистки или тайм-аут | Время распознавания, коэффициент и короткая причина; распознанный текст не теряется | запрос был |
| Ошибка распознавания | «Тест не выполнен: причина», кнопка снова доступна | нет |
| Модель не распознала текст | Время распознавания и строка «Модель не распознала текст» | нет |
| Уход с экрана или повторный запуск | Поздний ответ отбрасывается, карточка не меняется | запрос отменяется |

## Тексты результата

```
Распознавание: 10,6 с за 1,2 с (8,8×)
Очистка: 0,7 с
Всего: 1,9 с
```

Без очистки:

```
Распознавание: 10,6 с за 1,2 с (8,8×)
Очистка выключена, текст не отправлялся
```

## Время

- Распознавание измеряется вокруг `engine::transcribe_shared`, как
  сейчас. Загрузка модели и чтение файла не входят.
- Очистка измеряется от вызова `PostProcessor.run` до обратного вызова,
  то есть включает очередь, сеть и разбор ответа.
- Общее время равно сумме распознавания и очистки. При выключенной или
  ненастроенной очистке общее время не показывается.

## Приватность

- Аудио не покидает телефон: на сервер уходит только распознанный
  текст и только при включённой и настроенной очистке.
- Ключ и текст не пишутся в журнал. Текст больше не уходит в `logcat`
  из нативного слоя.
- Текст показывается только в карточке и окне «Подробнее».

## Отмена

- `PostProcessor.Task` уже отбрасывает ответ после отмены.
- Дополнительно номер прогона в активности: обратный вызов от прошлого
  прогона не может обновить карточку.
- `onStop` отменяет ожидающую очистку и сбрасывает состояние прогона,
  чтобы при возврате можно было запустить тест снова.

## Строки

Обновляются `values` и шесть переводов: `de`, `es`, `fr`, `it`, `pt`,
`ru`. Новые ключи: `desc_benchmark`, `bench_source`, `bench_result`
(многострочный), `bench_skip_disabled`, `bench_skip_unconfigured`,
`bench_no_text`, `bench_details`, `bench_details_title`,
`bench_details_text`, `bench_details_one`.

## Доступность

- Высота касания кнопок не меньше 48 dp, текстовая кнопка «Подробнее»
  использует стандартный стиль Material.
- Значение коэффициента и времени читается как обычный текст, без
  цветовой кодировки.
- Описание карточки и источник читаются экранным диктором как обычный
  текст.

## Что не входит

Отдельный экран отчёта, графики, история прогонов, сравнение устройств,
WER, выбор своей записи, автоматический подбор модели.
