# Security Screen: OVI-003

## Профиль и изменение

`standard`. Добавляется один сетевой запрос `GET` к тому же серверу,
который пользователь уже указал для очистки. Новых разрешений нет,
новых хранилищ нет.

## Данные и границы

| Данные | Класс | Куда попадают |
|---|---|---|
| Ключ API | секрет | заголовок `Authorization` к адресу пользователя |
| Список моделей | несекретный ответ | окно выбора, поле модели |
| Текст диктовки | личное | в этом запросе не участвует |

Запрос списка не содержит текста диктовки. Это меньше данных, чем у
запроса очистки.

## Угрозы и меры

| Угроза | Мера |
|---|---|
| Ключ уходит на другой хост через 30x | переадресация отключена, как в очистке |
| Ключ попадает в журнал | ключ не логируется, исключения не печатаются |
| Ответ огромный | предел 1 МиБ, список 500 имён, имя 200 символов |
| Ответ содержит управляющие символы | обрезка пробелов, удаление управляющих символов |
| Ответ подставляет HTML или ссылки | список показывает текст, без разметки |
| Чужой сервер отвечает 200 с мусором | строгий разбор, при неудаче сообщение |
| Запрос висит | сторожевой таймер 20 секунд, отмена при уходе с экрана |
| Ключ уходит по открытому HTTP | прежнее предупреждение об `http://` |
| Имя модели ломает тело запроса | `JSONObject` экранирует значение |

## Секреты и журналы

- Новый код не пишет в журнал ключ, адрес с параметрами и список моделей.
- Ошибки возвращаются короткими кодами, как в очистке: `timeout`,
  `network error`, `HTTP 401`, `unexpected response`.
- Значение ключа по-прежнему проверяется до заголовка, включая
  управляющие символы на краях.

## Негативные сценарии

| Сценарий | Поведение |
|---|---|
| 401 или 403 | сообщение о ключе, настройки не меняются |
| 404 | сообщение, что сервер не поддерживает список |
| Ответ не JSON | сообщение о разборе, ручной ввод |
| Пустой список | сообщение, ручной ввод |
| Одна модель | подстановка без окна |
| Уход с экрана | запрос отменяется, результат не показывается |
| Повторное нажатие | предыдущий запрос отменяется |

## Что не проверено

- Реальные ответы серверов пользователя.
- Поведение на телефоне и в эмуляторе: устройства в среде нет.
- Поведение серверов, которые отдают список без ключа, а чат требуют
  с ключом. Это допускается как штатный случай, ручной ввод остаётся.
