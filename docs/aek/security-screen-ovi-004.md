# Security Screen: OVI-004

## Что меняется в границах данных

| Поток | Было | Стало |
|---|---|---|
| Аудио теста | остаётся на телефоне | остаётся на телефоне |
| Распознанный текст теста | только `logcat` | карточка, окно «Подробнее», при включённой очистке уходит на сервер пользователя |
| Ключ | Keystore | без изменений |
| Новые разрешения | нет | нет |
| Новые зависимости | нет | нет |

Сеть используется только существующим `PostProcessor`, только при
включённом и настроенном переключателе очистки.

## Угрозы и меры

| Угроза | Мера |
|---|---|
| Текст диктовки попадает в журнал | В `main_activity.rs` убирается `log::info!` с текстом. В Java текст не логируется. |
| Текст уходит без ведома пользователя | Второй этап только при включённом переключателе; описание карточки прямо говорит об отправке. |
| Поздний ответ показывает чужой текст | Отмена в `PostProcessor` плюс номер прогона в активности. |
| Ответ сервера содержит разметку или ссылки | Показывается как обычный текст в `AlertDialog`, без WebView и без перехода по ссылкам. |
| Огромный ответ сервера | `OpenAiCompatibleClient` уже ограничивает размер ответа. |
| Ключ утекает через журнал исключения | `PostProcessor` уже не логирует текст исключения. |
| Запись теста выдаётся за собственную | Указание источника и лицензии в карточке и `docs/benchmark-audio.md`. |

## Проверки

- Поиск по коду: текст не передаётся в `Log`.
- JVM-тесты логики.
- Инструментальные тесты не требуют сети, кроме отдельного ручного
  прогона на телефоне пользователя.
- Снимок `dumpsys package` до и после: список разрешений не меняется.

## Остаточный риск

Сервер пользователя видит распознанный текст тестовой фразы. Фраза
публичная, личных данных в ней нет. Это то же поведение, что и в обычной
диктовке при включённой очистке.
