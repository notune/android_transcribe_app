# library-first-assessment

**Применяет:** Architect, Engineer.

**Когда:** нужна новая зависимость или нестандартная функция, либо есть соблазн написать своё вместо готового.

## Порядок работы
Проверь повторное использование текущего кода и возможностей платформы. Сравни 2–3 зрелых решения: совместимость, релизы, сопровождение, лицензия, уязвимости, API по первоисточникам, стоимость владения. Обоснуй собственный код, если выбран.

## Результат
Краткий проверяемый артефакт, явные допущения и перечень того, что не проверено. Не утверждай, что команда или скилл фактически выполнялись, без подтверждения.
