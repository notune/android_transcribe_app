# Изменения

## 0.3.0 — 28.11.2026

Совместимость: пакет `dev.notune.transcribe` и minSdk 26 не менялись.
Настройки прежней версии сохраняются. Добавлено разрешение `INTERNET`: оно
нужно только для необязательной очистки текста. Очистка по умолчанию
выключена, без неё приложение работает как раньше и ничего не отправляет.

### Добавлено

- Необязательная очистка распознанного текста языковой моделью через
  OpenAI-совместимый сервер. Аудио остаётся на телефоне, уходит только
  текст.
- Выбор модели очистки из списка, который отдаёт сервер.
- Кнопка проверки связи с сервером.
- Тест скорости на встроенной русской записи: время распознавания,
  коэффициент реального времени, время очистки и общее время. Окно с
  распознанным и очищенным текстом.

### Изменено

- Распознавание переведено на GigaAM v3.
- Тест скорости больше не использует английскую запись и проверяет оба
  этапа.
- Настройки теста фиксируются при запуске, поэтому правка полей во время
  прогона не меняет уже начатый тест.

### Безопасность

- Ключ хранится в Android Keystore и не пишется в журнал.
- Если сохранить ключ не удалось, текст не отправляется со старым ключом.
- Поздний результат отменённой диктовки или теста отбрасывается и не
  попадает в другое поле.

### Проверки

- JVM-тесты: 51, падений нет.
- Инструментальные тесты на Samsung SM-F966B: 8, падений нет.
- Независимая проверка кода пройдена.
